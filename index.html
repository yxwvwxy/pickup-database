Local Pickup Tracker

About

Daily local pickups for an EWR warehouse operation — 150+ partners, 1,500+ trips, about $450k monthly cost.

Dispatchers paste each carrier’s list. The tracker parses jobs and official station names, fills today’s log one partner per row, then confirms address, state, and price.

If two partners share a truck, Confirm uses the shared rate. If each has their own truck, it uses the solo rate.

  • Paste daily carrier lists
  • Parse jobs and match official names
  • Fill today, enter pallet counts, Confirm prices

This public demo is anonymized. Names are Partner A / Carrier A. It shows process logic only, not live data.
